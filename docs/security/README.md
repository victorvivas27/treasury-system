# Documentación de seguridad

El [informe general de auditoría](../../SECURITY_AUDIT.md) reúne los hallazgos. Cada hallazgo que trabajemos tendrá su propia carpeta aquí, con sus informes y evidencias documentales.

| Hallazgo | Documentación |
|---|---|
| SA-01 | [Informes y verificación](sa-01/README.md) |
| SA-03 | [Corrección y verificación](sa-03/README.md) |
| SA-04 | [Corrección y verificación](sa-04/README.md) |

Para los siguientes hallazgos, usar `sa-02/`, `sa-03/`, etc., y añadir su enlace a esta tabla. Los tests permanecen en `backend/src/test`, junto al código que los ejecuta; los reportes generados por Gradle permanecen en `backend/build`.
