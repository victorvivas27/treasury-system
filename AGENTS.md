# Instrucciones del proyecto

Consultar `.agents/AGENTS.md` para las reglas y la documentación del proyecto.

## Viewport de referencia para desktop

- Usar siempre **1216 × 552 px** (ancho × alto, en píxeles CSS) como viewport de referencia al diseñar, ajustar y validar la interfaz desktop.
- Esta medida corresponde al área visible del navegador del usuario.
- Mantener el diseño adaptable a otros tamaños de pantalla.
